# Projeto Prático : Portal de notícias

Este repositório contém a resolução obtida no projeto prático "Portal de Notícias" do módulo "Layouts Avançados com CSS" da Formação Full-Stack da Rocketseat. 

Veja o resultado em : https://erick-p-calauro.github.io/projeto-portal-noticias

## Quais conhecimentos foram demandados ?

O projeto foi realizado utilizando exclusivamente HTML e CSS. O objetivo dessa atividade era praticar conceitos mais avançados nos tópicos de layout em CSS, principalmente layouts modernos do tipo Flexbox e Grid.

## Créditos

O design do desafio foi fornecido como material pela Rocketseat.
A implementação é de minha autoria, desenvolvida com apoio das aulas contidas no módulo indicado.
